Configurando o cliente HTTP

Por Marina Souza · atualizado em 2 de junho de 2025

O HttpClient é o ponto de entrada para todas as chamadas à API. Ele mantém um pool de conexões, aplica retries com backoff exponencial e respeita os cabeçalhos Retry-After enviados pelo servidor. Veja também o guia de tratamento de erros e a RFC 9110.

ÍCONE-DECORATIVO

Instalação

Instale o pacote pelo gerenciador de pacotes do seu projeto:

npm install @acme/http --save
# ou
pnpm add @acme/http

Opções

As opções abaixo podem ser passadas ao construtor. Valores em milissegundos.

Opção Tipo Padrão Descrição
timeout number 30000 Tempo máximo de uma requisição.
retries number 3 Tentativas em erros 5xx e 429.
backoffMs number 250 Espera inicial entre tentativas (dobra a cada uma).
maxSockets number 64 Conexões simultâneas por host | pool.

Exemplo

import { HttpClient } from '@acme/http'

const client = new HttpClient({
  baseUrl: 'https://api.acme.dev',
  timeout: 10_000,
  retries: 5
})

const res = await client.get('/v2/orders', { query: { limit: 50 } })
console.log(res.status, res.data.items.length)

Atenção: nunca desative a verificação de TLS em produção.

Glossário

Backoff
Intervalo crescente entre tentativas.
Pool
Conjunto de conexões TCP reutilizadas.

Proxies

  1. Defina HTTPS_PROXY no ambiente, ou
  2. passe proxy: 'http://proxy.local:3128' nas opções;
    • autenticação básica é suportada na URL;
    • proxies SOCKS exigem o pacote @acme/socks.
