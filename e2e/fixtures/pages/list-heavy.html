Ferramentas de linha de comando

Atualizada em 2025.

  1. ripgrep — busca recursiva por regex, respeita .gitignore.
  2. fd — alternativa simples e rápida ao find.
  3. bat — cat com destaque de sintaxe e integração com git.
  4. jq — processador de JSON na linha de comando.
  5. fzf — busca difusa interativa.
  6. htop — monitor de processos interativo.
  7. tmux — multiplexador de terminal.
  8. delta — pager de diffs com destaque.
  9. hyperfine — benchmarks de comandos.
  10. tokei — conta linhas de código por linguagem.
  11. zoxide — cd que aprende os diretórios mais usados.
  12. eza — ls moderno com ícones e git.
  13. dust — du intuitivo.
  14. procs — ps moderno.
  15. sd — find & replace intuitivo.
  16. xh — cliente HTTP amigável.
  17. httpie — cliente HTTP para humanos.
  18. yq — jq para YAML.
  19. gron — torna JSON grepável.
  20. entr — roda comandos quando arquivos mudam.
  21. watchexec — executa comandos ao detectar mudanças.
  22. lazygit — interface de terminal para git.
  23. tig — navegador de repositórios git.
  24. ncdu — analisador de uso de disco.
  25. mtr — traceroute + ping.
  26. dog — cliente DNS.
  27. glow — renderiza Markdown no terminal.
  28. btop — monitor de recursos.
  29. difftastic — diff estrutural.
  30. just — executor de comandos tipo make.

Atalhos úteis

Tecla Ação
Ctrl+R busca no histórico
Ctrl+A início da linha
Alt+. último argumento
